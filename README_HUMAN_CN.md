# PICSIMU 人类快速说明

PICSIMU 是一个 1D 圆柱坐标 PIC-MCC 模拟，用于生成高压碰撞鞘层条件下的朗缪尔探针
I-V 曲线。项目目标是生成可靠的合成数据，支撑等离子体参数推断与机器学习诊断。

## 警告

不建议人类使用者自行修改任何代码，代码修改应由最低为 DeepSeekR1 内核的 agent 执行。

## 项目在做什么

- 1D 径向模拟圆柱探针周围鞘层
- 追踪电子/离子并保持角动量守恒
- 求解圆柱 Poisson 方程，加入离子-中性 CEX 与电子-中性简化碰撞
- 输出 I-V 曲线、电势与密度分布

## 为什么要做

- 覆盖高压碰撞 regime (1-200 Torr)，弥补 OML 低压模型的不足
- 为 ML 诊断生成高压 I-V 合成数据
- 面向工业与大气压等离子体应用

## 目录结构

- `core/`：Numba 加速物理核心
- `frontend/`：Streamlit 前端
- `benchmarks.py`：基准测试命令行入口
- `run_physics_accurate.py`：主测试/数据生成命令行入口
- `results/`：基准测试输出
- `README.md`：完整技术细节（AI/automation 参考）

为保持仓库清晰，根目录历史实验/调试脚本已清理，仅保留上述主入口脚本。

## 快速运行

```powershell

```


## 主要输入

- 气压 (Torr)、密度 (m^-3)、电子温度 (eV)
- 探针偏压 (V)
- 数值设置：网格数、时间步长、粒子数

## 输出

- I-V 曲线数据（总电流/电子/离子）
- 电势与密度分布曲线
- `results/` 中的基准测试图

## 验证状态（摘要）

- Poisson 求解器：真空圆柱电容器测试通过
- 电子温度检查：通过（Te ≈ 2.02 eV）
- OML 离子动力学：通过（R² = 0.993）
- 碰撞阻尼：通过（离子电流随压强抑制）

## Benchmark 说明

- 真空圆柱电容器：验证圆柱 Poisson 求解器与 1/r 几何项
- 电子温度检查：验证速度采样与 Boltzmann 关系（retarding 区）
- OML 离子动力学：验证角动量守恒与 I_i^2 ∝ |V| 线性
- 碰撞阻尼：验证 CEX 碰撞下离子电流随压强降低

## 物理模型假设（简要）

- 1D 径向圆柱几何，无轴向/方位角空间变化
- 仅静电场，无磁场
- 物种为电子与单电荷离子（氩）
- 碰撞：离子-中性 CEX + 弹性散射；电子-中性含弹性/激发/电离
- 支持 LXCat 能量依赖截面（可选）
- 电离可生成二次电子/离子（可选，简化能量均分）
- 边界：探针/外壁吸收，外边界注入以维持密度

## 局限

- 仅 1D 径向模型（无轴向/方位角空间变化）
- 碰撞模型仍有简化（若未提供 LXCat 数据则退化为常数截面）

提示：默认配置会尝试读取仓库根目录的 `CS.txt` 作为本地 LXCat 导出数据。
- 静电近似（无磁场）

完整技术细节请查看 `README.md`。

## 2026-03-11 实验对比更新（Kakati 2017，0.15 mm 探针）

参考文献：
- Kakati et al., *Scientific Reports* 7, 490 (2017), PMCID: PMC5593904
- 对比对象：Figure 1 的 clean H-plasma I-V 曲线（图上读点）

本次仿真采用与论文一致的探针几何尺寸，并在不强制锁定 `Te`、`N0`
标称值的前提下，调参使曲线形状与电流量级接近实验。

### 仿真设置（当前可复现配置）

- 探针：直径 `0.15 mm`，长度 `10 mm`
- 几何：`R_MIN = 7.5e-5 m`，`R_MAX = 2.0e-3 m`
- 扫描范围：`-30 V` 到 `+80 V`，共 `12` 点
- 压强：`0.08 Pa`（`8e-4 mbar`）
- 离子质量：`m_i = 1.67262192369e-27 kg`（H+）
- 调参后模型参数：
  - `N0 = 9.6e15 m^-3`
  - `Te = 0.6432 eV`
  - `Ti = 0.2167 eV`
  - `V_WALL = -9.0938 V`
  - `sigma_cex = 1.7e-19 m^2`
  - `ION_INJECTION_BOHM = False`
- 数值设置：
  - `n_particles = 6000`（每物种）
  - `n_initial_burn_in = 2800`
  - `n_burn_in = 1500`
  - `n_sampling = 2200`
  - `ramp_steps = 180`
  - `seed = 20260314`
  - 开启自适应稳定性：`ADAPTIVE_STABILITY = True`
  - 运行末状态：`dr = 8.75e-6 m`，`dt = 1.890431e-12 s`
